# Aplicação

Esta é a área de trabalho da aplicação. Os arquivos de infraestrutura e automação não aparecem neste ambiente.

## Primeiro passo

1. Crie ou adicione os arquivos da aplicação nesta pasta.
2. Use `src/` para o código-fonte, quando o projeto precisar dele.
3. A aplicação poderá ter seu próprio `package.json`, README e dependências.

## Commit

Depois de adicionar arquivos ao Git, use o comando abaixo para criar um commit guiado:

```bash
pnpm --dir ../infra commit
```

> Esse comando executa a automação da empresa sem exibir os arquivos de DevOps no Explorer.
